# Задача. Реализовать микросервисную архитектуру и простого telegram-бота

### Аргументация
Чтобы не делать фронт, можно воспользоваться различными интеграциями с существующими сервисами, например с telegram.

### Требования
- Микросервисная архитектура
- Телеграм бот должен уметь:
  - получать файлы от пользователя
  - возвращать файлы пользователю
  - выводить описание ошибок
- Обмен информации между сервисами должен выполняться через Feign по названию сервиса (без указания точных адресов)

### Вариант реализации
Микросервисы:
- eureka-service
- config-service
- converter-service
- converter-bot-service (отдельный сервис)

С ограничением по IP могут возникнуть трудности, можно попробовать доработать ограничение и учитывать UserId из телеграмма или сделать отдельный хост (API) для локального использования.
