# Задача. Реализовать ограничение использования API по IP через Аспектно-Ориентированное программирование (АОП).

### Аргументация
Чтобы хоть как-то защититься от ddos-атак или злоупотребление сервисом, нужно реализовать ограничение на использование сервиса.  

### Требования
- Все проверки выполнять через АОП
- Код должен быть хорошо читаем и задокументирован (комментарии javadoc)

### Вариант реализации
Самое простое получать IP адрес из запроса и проверять ограничение на к-во запросов в час.  
Как вариат использовать RateLimiter или сохранять в базу IP вместе с задачей на конвертацию.
